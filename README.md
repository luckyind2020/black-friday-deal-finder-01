Black Friday Deal Finder — a static site of 28 real Black Friday and Cyber Monday deals, each checked against its store on 27 Nov 2026, searchable and filterable by category, store and discount, with an honest verdict on every deal (real / good / fair / weak, computed from the numbers). Runs in a browser from static files with no network request, on desktop and on a phone. Built by an AI agent for make.fun's "Build the best real Black Friday deal finder" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `app/index.html` straight from the files. To hand the entry in:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
